بدون تثبيت وبدون أي مكتبات خارجية. الأداة تقرأ `git log`، وتؤلّف قطعة موسيقية، وتكتب ملف HTML واحدًا تفتحه في المتصفح وتضغط تشغيل.

## كيف يتحوّل التاريخ إلى موسيقى

| في المستودع | في الموسيقى |
|---|---|
| الـcommit | نغمة واحدة |
| صاحبه | الآلة: أكثر أربعة مساهمين يعزفون **العود** و**القانون** و**الناي** و**الكمنجة**، والباقون ينضمّون للعود |
| أسطر مضافة / محذوفة | اللحن يصعد / ينزل |
| commit كبير | نغمة أطول مع زخرفة |
| فترة هدوء | سكتة |
| إصلاح (fix) | «تك» على حافة الدربكة |
| دمج (merge) | «دُم» في وسط الدربكة |
| تراجع (revert) | هزّة رق، واللحن يتراجع عن خطوته الأخيرة |
| أول الـcommits | تقاسيم حرّة على العود |
| آخر commit | قفلة تعود إلى درجة الركوز |
| نشاط المستودع | سرعة الإيقاع |

كل ثماني نغمات تعود الجملة إلى الركوز أو الغمّاز كما في اللحن المقامي، ثم يحمل الإيقاع بقية القطعة: مقسوم افتراضيًا، أو بلدي، صعيدي، ملفوف، وحدة.

أثناء العزف تظهر رسائل الـcommit كأنها كلمات أغنية، وتُرسم كل نغمة ست عشرة مرة حول الخاتم السليماني (النجمة الثُّمانية). في النهاية تحصل على وردة لا يصنعها أي مستودع آخر.

### أرباع تون حقيقية

الصوت يُولَّد بدقة الأرباع (الدرجة الثانية في البياتي على بُعد 150 سنت، والثالثة في الراست على 350)، والعود والقانون أوتار منقورة بخوارزمية Karplus-Strong. وملف MIDI يحتفظ بالأرباع عبر pitch bend لكل نغمة.

## أي مقام لمستودعك؟

أول قاعدة تنطبق هي المعتمدة:

| المقام | الطابع | متى |
|---|---|---|
| سيكاه | الرقّة | أقل من 12 commit |
| صبا | الحزن | 30% أو أكثر إصلاحات |
| حجاز | الشوق والبُعد | 20% أو أكثر بين منتصف الليل والخامسة فجرًا |
| كرد | التأمل | يحذف 75% على الأقل مما يضيف |
| نهاوند | الحنان | 35% أو أكثر في عطلة نهاية الأسبوع |
| راست | الفخر والأساس | شخص واحد كتب 75% أو أكثر |
| بياتي | الفرح الشعبي | ستة مساهمين منتظمين أو أكثر |
| عجم | الإشراق | ينمو ثلاث مرات أسرع مما يتقلّص مع قليل من الإصلاحات |
| بياتي | الفرح الشعبي | ما سبق لا ينطبق |

## الخصوصية

كل شيء يعمل على جهازك ولا يُرفع شيء. ملف HTML يحتوي أسماء المساهمين وعناوين الـcommits وأوقاتها وعدد الأسطر فقط، بدون بريد إلكتروني أو مسارات ملفات أو كود. استخدم `--anonymous` قبل مشاركة صفحة مستودع خاص.

## ملاحظة للموسيقيين

الأبعاد تقريبية على سلّم 24 ربع تون متساوٍ، والعازفون الحقيقيون يلوّنون الأرباع بحسب المقام والمدرسة. التصحيحات من أهل العزف مرحّب بها جدًا.
